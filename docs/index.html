Frequently Asked Questions

Everything you need to know about Arcile.

How do I know Arcile is 100% offline and private?

Arcile does not declare Android's android.permission.INTERNET permission in its manifest and has no ads, trackers, or telemetry. Preferences and listening history stay on your device. Files leave Arcile only when you choose to share or open them with another app.

What happens to my Encrypted Vault files if I uninstall the app?

Portable Vaults saved on your internal storage or SD card remain intact and AES-256-GCM encrypted. App-private vaults live inside Arcile's private app data folder, which Android deletes upon uninstallation. We recommend using Portable Vaults for long-term storage across reinstalls or device transfers.

Can Arcile install single APKs and split APK containers (.apks, .xapk)?

Yes. Arcile includes a native package installer built directly on Android's PackageInstaller API. You can inspect version codes, view package icons, and install single .apk files or multi-file split APK containers (such as .xapk, .apks, and .apkm) without third-party installer utilities.

How does Arcile handle Android 11+ storage permissions?

Arcile requests Android's All Files Access (MANAGE_EXTERNAL_STORAGE) permission to manage shared storage. Android still restricts access to protected locations such as Android/data and Android/obb; this permission does not bypass those restrictions.

Where are deleted files moved and how do I restore them?

On storage classified as permanent, deleted files move into a hidden .arcile/.trash directory on the same volume. Arcile preserves recovery metadata so you can preview or restore them, choosing another folder when needed and keeping both files if names conflict. Temporary storage uses permanent deletion instead of Trash.

Is Arcile open-source and how do I submit feedback or report bugs?

Yes. Arcile is source-available under the Tremors Source License (TSL). View the source, report bugs through GitHub Issues, or join the Discord community.
