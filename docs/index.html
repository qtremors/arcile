Frequently Asked Questions

Everything you need to know about Arcile.

How do I know Arcile is 100% offline and private?

Arcile does not declare Android's android.permission.INTERNET permission in its manifest. Because the operating system blocks all network sockets at the kernel level, it is physically impossible for the app to send data, track usage, or upload telemetry to any server.

What happens to my Encrypted Vault files if I uninstall the app?

Portable Vaults saved on your internal storage or SD card remain intact and AES-256-GCM encrypted. App-private vaults live inside Arcile's private app data folder, which Android deletes upon uninstallation. We recommend using Portable Vaults for long-term storage across reinstalls or device transfers.

Can Arcile install single APKs and split APK containers (.apks, .xapk)?

Yes. Arcile includes a native package installer built directly on Android's PackageInstaller API. You can inspect version codes, view package icons, and install single .apk files or multi-file split APK containers (such as .xapk, .apks, and .apkm) without third-party installer utilities.

How does Arcile handle Android 11+ storage permissions?

Arcile requests Android's All Files Access (MANAGE_EXTERNAL_STORAGE) permission to manage your storage. For system-restricted paths like Android/data or Android/obb, Arcile uses Android's Storage Access Framework (SAF) folder picker to grant explicit scoped access.

Where are deleted files moved and how do I restore them?

Deleted files are safely moved into a hidden .arcile/.trash directory on the same storage volume. Arcile preserves original file metadata so you can preview, restore items back to their exact original locations, or empty the trash permanently when you need space.

Is Arcile open-source and how do I submit feedback or report bugs?

Yes. Arcile is source-available under the Tremors Source License (TSL). You can view the source code, open issue reports, suggest features, or participate in discussions on our official GitHub Issues repository page.
